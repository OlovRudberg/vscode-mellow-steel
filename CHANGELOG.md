# Mellow Steel Theme Change Log

All notable changes to the "mellow-steel-theme" extension will be documented in this file.

Check [Keep a Changelog](http://keepachangelog.com/) for recommendations on how to structure this file.

## [1.2.0] - Robust settings

- Added colors to prevent underlaying theme changes to not matter
- The purpose for this change is that a vscode update messed with
some of the coloring, and by adding colors to all settings, this theme
is not reliant on underlaying changes in vscode.


## [1.1.0] - Color additions

- Added colors for secondary buttons and hover functionality.
- Added color setting for main foreground text.
- Added color settings for git operations.


## [1.0.0] - The initial release 

- Initial release of the light theme.
- Added a pyproject.toml file for general information and version tracking.
